# The Schild Family Archive

A free, static family history website for the Schild family — home, family tree, timeline, and stories & photos pages.

Plain HTML/CSS, no build step, no frameworks. Hosted for free on GitHub Pages.

## Structure

- `index.html` — Home
- `family-tree.html` — placeholder family tree
- `timeline.html` — placeholder timeline of events/migrations
- `stories.html` — placeholder stories, photos, and documents
- `style.css` — shared styles
- `assets/shield.svg` — the Schild shield motif used across the site

## About the shield motif

The shield design (azure field, red horizontal band, three small silver escutcheons) is inspired by a heraldic blazon historically associated with the Schild / Schildt name. It is decorative and has **not** been verified as a grant of arms belonging to this specific family line. See the note on the Home page.

## Editing

Open any `.html` file in a text editor and fill in the bracketed placeholders (e.g. `[Ancestor Name]`) with real names, dates, and stories. No build tools are required — just edit and save.
